# 💰 Expense Tracker

An intuitive and easy-to-use Expense Tracker application to manage your daily income and expenses.  
Track your spending, analyze your habits, and stay on top of your budget effortlessly.

---

## 🚀 Features

- 📅 Add, edit, and delete expenses/income
- 📊 View daily, weekly, and monthly summaries
- 🔍 Filter transactions by category or date
- 💾 Persistent storage using local database / Firebase
- 📈 Visual charts to analyze spending trends
- 🌙 Light and Dark mode support (optional)
